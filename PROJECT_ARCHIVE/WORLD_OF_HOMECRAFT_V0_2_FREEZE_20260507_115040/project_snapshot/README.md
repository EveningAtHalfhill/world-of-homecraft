# World of Homecraft / 魔坊世界

**EN**  
If the heroes of Azeroth stopped fighting raids,  
and started taking home life seriously.

**CN**  
如果艾泽拉斯的英雄不再征战，  
而开始认真生活。

## English Intro

World of Homecraft is a folk Azeroth archive for the hours after the armor comes off.

No rankings.  
No raid schedules.  
No urgency.

Just old tavern notes, quiet rooms, neighbor complaints, class-themed dwellings, and places people still talk about after midnight. Some rooms are cozy. Some are suspicious. Some rooms should probably not exist.

World of Homecraft is not a copy of Warcraft.  
It is a small folk fantasy about what Azeroth might feel like after work.

## 中文介绍

魔坊世界记录的是卸甲之后的艾泽拉斯。

这里没有 DPS 排名。  
没有装备毕业。  
也没有非去不可的路线。

这里只有：酒馆旧告示，邻居低声抱怨，主城角落里的家宅，NPC 留下的几句点评，以及那些半夜之后仍被人谈起的地方。有些房间很温暖，有些房间很可疑，有些房间也许本不该存在。

World of Homecraft 不是 Warcraft 的复制品。  
它更像是：Warcraft 下班之后的民间幻想。

## What You May Find Here / 你可能会在这里找到

- Class-themed dwellings / 职业主题居所
- Tavern rumors and neighbor complaints / 酒馆传闻与邻居抱怨
- NPC remarks / NPC 留下的点评
- Lore-flavored locations instead of coordinates / 不是坐标，而是世界里的传闻地点
- Rare, epic, legendary, and mythic affixes / 稀有、史诗、传说、神话词缀
- Dynamic class atmospheres / 职业动态氛围
- Numbered home records / 带编号的家宅档案
- PNG poster export / 可导出的世界档案海报
- Pure static HTML, CSS, and JavaScript / 纯静态页面

Supported class records / 已收录职业档案：

```text
术士、圣骑士、盗贼、萨满、死亡骑士、战士、猎人、法师、牧师、德鲁伊、武僧、恶魔猎手、唤魔师
```
