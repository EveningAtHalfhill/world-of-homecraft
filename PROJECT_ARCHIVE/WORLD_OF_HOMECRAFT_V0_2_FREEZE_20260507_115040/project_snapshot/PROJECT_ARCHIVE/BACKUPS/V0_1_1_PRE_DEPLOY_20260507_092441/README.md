# World of Homecraft / 魔坊世界

魔坊世界是一个会生成职业家宅、坊间传闻与 NPC 吐槽的艾泽拉斯生活幻想工具。纯静态页面，不需要后端、网络或依赖安装。

## Project Info

- 展示名：World of Homecraft / 魔坊世界
- 内部项目名：wow-home-generator
- 当前版本：V0.1
- V0.1 主题：职业家宅初版

支持职业：

```text
术士、圣骑士、盗贼、萨满、死亡骑士、战士、猎人、法师、牧师、德鲁伊、武僧、恶魔猎手、唤魔师
```

功能：

- 随机生成职业家宅主题名
- 随机生成 3 个核心家具
- 随机生成 3 个摆放坐标
- 随机生成 2 到 4 个职业专属稀有词条
- 支持普通、稀有、史诗、传说、神话词条稀有度
- 每个职业有职业徽记、动态职业氛围和 NPC 点评
- 生成装修风格说明和坊间传闻
- 使用浏览器原生 canvas 导出 PNG 海报截图
