# VERSION V0.1 RELEASE

## Release Name

World of Homecraft / 魔坊世界

## Internal Project Name

wow-home-generator

## Release Positioning

V0.1 is the first public concept freeze: `职业家宅初版`.

This version focuses on class-themed home generation, world-flavor writing, tavern rumors, NPC commentary, rare affixes, and shareable poster output.

## V0.1 Features

- World of Homecraft / 魔坊世界 formal display name.
- 13职业家宅生成.
- 动态职业背景.
- PNG 海报导出.
- 坊间传闻.
- NPC 点评.
- 稀有词缀系统.
- 神话词缀.
- 职业世界观风格文案.
- 方案编号系统.

## Freeze Notes

This release freezes the current static HTML/CSS/JavaScript version as the first public V0.1 concept.

No backend, npm, network dependency, database, or third-party CDN is required.

The app remains directly runnable by opening `index.html` in a browser.
