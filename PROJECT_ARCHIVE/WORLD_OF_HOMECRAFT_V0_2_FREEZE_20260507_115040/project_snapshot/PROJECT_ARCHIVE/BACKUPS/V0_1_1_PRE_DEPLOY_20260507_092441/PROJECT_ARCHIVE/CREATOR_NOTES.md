# CREATOR NOTES

## Core Idea

“希望创造一个像真正活着的艾泽拉斯世界。”

The public name is now `World of Homecraft / 魔坊世界`.

The internal engineering name remains `wow-home-generator`.

V0.1 is `职业家宅初版`: a first public concept centered on class-themed homes, NPC commentary, tavern rumors, rare affixes, and shareable posters.

The next creative milestone is V0.2《酒馆与邻居》.

This project is not only about generating a furniture checklist. The goal is to make the page feel like a small window into a living game world, where every class has neighbors, rumors, strange rooms, awkward visitors, and stories that continue beyond the player character.

## Creative Pillars

### Tavern NPCs

The world should feel like it has voices. Tavern keepers, class leaders, guards, couriers, and wandering adventurers should all be able to comment on a home design.

### Passerby Commentary

路人吐槽 adds warmth and believability. A house feels more real when neighbors complain about wolf howls, fel smoke, floating tea kettles, or suspicious underground doors.

### Murloc Easter Eggs

鱼人彩蛋 should appear as hidden jokes, rare events, or unexpected rumor lines that make the world feel playful.

### Kobold Candles

狗头人蜡烛 is a perfect small-world detail: strange lighting, tunnel rooms, candle hoarding, and suspicious basement design can all become future generation material.

### Ogre Homes

食人魔家宅 suggests a bigger design direction: not every home should be elegant. Some should be loud, oversized, badly planned, funny, and full of personality.

### World Lived-In Feeling

世界生活感 matters more than perfect decoration. The homes should suggest habits, conflicts, gossip, maintenance problems, class rituals, and local legends.

### Player Shareability

玩家分享感 should come from the generated story. A good result should feel like something a player wants to screenshot because it says something funny and specific about their class identity.
