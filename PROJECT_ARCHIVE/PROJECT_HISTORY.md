# PROJECT HISTORY

## Project Name

- 展示名：World of Homecraft / 魔坊世界
- 内部工程名：wow-home-generator
- 当前版本定位：V0.1 职业家宅初版

## Project Goal

Create a browser-only World of Warcraft inspired home design generator that feels like a living Azeroth lifestyle artifact: part game UI, part tavern rumor board, part shareable character-class poster.

The formal public display name was established as `World of Homecraft / 魔坊世界`, while the internal engineering folder and project name remain `wow-home-generator`.

## First Version

The first version established a static HTML/CSS/JavaScript tool that can be opened directly with `index.html`, without a backend, network access, npm, or third-party dependencies.

## Major Creative Systems

### Class Home Generator

The project generates class-themed home design plans for World of Warcraft style characters, including themes, furniture, placement coordinates, class flavor, and shareable poster data.

### NPC Commentary

Each class can receive a short NPC comment with a highlighted speaker name. The tone is lightly humorous and written like game quest text or tavern chatter.

### Tavern Rumors

The original social-title idea was replaced by `坊间传闻`, a rumor system that displays 2 to 3 class-flavored tavern, city, or adventurer gossip lines per generation.

### Rare Affixes

The generator includes class-specific affixes with rarity tiers: normal, rare, epic, legendary, and low-probability mythic affixes.

### PNG Export

The page exports a shareable PNG poster using browser-native canvas. The image includes the class, plan number, emblem, theme, furniture, coordinates, affixes, NPC comment, and rumors.

### Dynamic Class Backgrounds

Each class changes the page atmosphere through CSS variables, gradients, glow effects, and symbolic class emblems.

### Codex Collaboration

The project was developed through iterative collaboration with Codex, progressively moving from a small static generator into a more complete game-poster style creative tool.

## Roadmap Note

V0.1 is positioned as `职业家宅初版`.

The next planned direction is V0.2 `酒馆与邻居`, focusing on tavern gossip, neighbor reactions, and stronger everyday-world storytelling.
